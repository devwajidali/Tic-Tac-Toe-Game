# Tic Tac Toe Game

## 📌 Project Overview

This is a fully functional **Tic Tac Toe Game** built using **HTML5**, **CSS3**, and **JavaScript**. The game allows two players to play turn by turn, automatically detects the winner or a draw, and provides options to start a new game or restart the current game.

This project was created to practice JavaScript DOM manipulation, game logic, event handling, and responsive UI design.

---

## 🚀 Features

* 🎮 Two-player gameplay (X vs O)
* ✅ Automatic winner detection
* 🤝 Draw detection
* 🏆 Winning message display
* 🔄 Restart Game button

## 🎮 How to Play

1. Player O** starts the game.**
2. Players take turns placing their marks (**X** and **O**) on the board.
3. The first player to align **three marks** horizontally, vertically, or diagonally wins.
4. If all cells are filled without a winner, the game ends in a **Draw**.
5. Click **Restart Game** to reset the current match.
6. Click **New Game** to start a fresh game after a win or draw.
